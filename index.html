0-2. 강의 끝나면 이렇게 나옵니다 — 산출물 미리보기

강의를 끝까지 따라오면, 다음 7섹션이 채워진 보고서를 손에 들고 자리로 돌아갑니다. 지금 양식이 머리에 들어오지 않아도 괜찮습니다 — 남은 8개 PART(01~08)를 거치면서 각 섹션이 어떻게 채워지는지 직접 만들어봅니다.

SECTION 1~3배경 · 후보 개요 · 선정 기준

SECTION 6~7리스크 · 실행 일정

각 후보별 리스크와 대응 방안, 9월 15일 제출까지의 작성 일정. C의 담당·일정과 실제 도입은 미정으로 유지. 퓨샷 + 본인 판단으로 마무리합니다.

0-3. 역할 · 자원 · 보안 룰

강의 내내 김대리 입장에서 작업합니다. 강사가 자료 3종을 미리 준비해 두었습니다.

실습용 부서협업 TF의 김대리. 교사 지원 서비스 개선 보고서를 작성하고 2026년 9월 14일 박리더 검토를 거쳐 9월 15일 제출합니다.

GOAL의사결정 보조

박리더가 A의 초안 검토와 B의 근거 정리를 확인할 수 있게 합니다. C의 담당·일정은 미정으로 남기고, 실제 도입 결정에 앞서 확인할 조건과 리스크를 보여 줍니다.

CONSTRAINT외부 AI 입력 금지

미공개 교재 원고·문항, 계약·실적, 교사·학생 개인정보는 승인되지 않은 외부 AI에 입력하지 않습니다. TF·회의록·보고서·실습 데이터·보안 조건은 교육용 가상 설정이며 미래엔의 실제 조직·정책·문제·성과를 뜻하지 않습니다. 개선안은 공개 웹 근거와 실습 가정을 구분해 작성합니다. 실제 업무 적용 시에는 회사 보안 정책과 계정 유형(개인용/기업용)을 먼저 확인합니다.

이 교안의 자료를 읽는 기준. 공개 서비스의 실제 안내와 교육용 설정을 구분합니다. TF·인물·회의·일정·보고서·업무 데이터·실습 보안 조건은 가상이며 미래엔의 실제 문제나 내부 정책을 나타내지 않습니다. 엠티처·미래엔 참고서 자료실·초코클래스의 공개 웹 안내는 조사 근거입니다. 개선안과 기대 효과는 학습자가 검증할 제안·가설입니다.

PART 01 첫 시도

평범한 입력은 평범한 출력을 만든다김대리가 평소처럼 한 줄로 시켜본다 — 어디서 막히는지 직접 부딪힙니다

1-1. 평범한 입력의 한계 — 김대리의 첫 시도

김대리는 박리더 지시를 받고 자리에 돌아왔습니다. 평소처럼 ChatGPT 창을 열고 한 줄로 물어봅니다. 좋은 프롬프트를 먼저 보여드리지 않습니다 — 왜 그게 필요한지 체감하려면, 평범한 시도가 어디서 막히는지 직접 봐야 합니다. 여러분도 지금 ChatGPT를 열고 이 한 줄을 그대로 입력해 보세요 — 결과 창을 닫지 말고 띄워두면, PART 02에서 3요소를 적용했을 때 내 화면에서 직접 Before / After를 비교할 수 있습니다.

어떤 교사 지원 업무를 개선하는지, 대상 서비스와 A·B·C 후보가 무엇인지 없습니다. 가장 핵심 정보가 비어있습니다.

빈자리 4FORM · 양식 없음

제공된 7섹션 실습용 양식이 있는데도, 한 줄 프롬프트는 이를 모릅니다. AI 결과는 회사 양식과 다른 모양이 나옵니다.

빈자리 5DATA · 개선 후보 정보 없음

공개 서비스가 무엇을 안내하는지, 개선안의 근거와 검증할 가설이 무엇인지 AI는 모릅니다. 외부 리서치 없이는 "~를 잘 분석해야 합니다"같은 일반론만 나옵니다.

# 역할·목적 가상 교사 연수 운영경비 영수증을 읽어 검토용 엑셀 표로 정리하는 챗봇이다. 실제 정산 승인·비용 인정·세무 판단은 하지 않는다. # 작업 순서 - ZIP을 받으면 먼저 압축을 풀어 이미지 목록을 확인해. - OCR 단계는 이미지를 직접 읽어 진행하고, Code interpreter는 압축 해제와 추출 후 엑셀 생성에 사용해. - 이미지를 합쳐 읽거나 내용을 임의 변형하지 말고 파일 1개씩 순서대로 추출해. 파일명과 해당 행의 대응을 유지해. - 각 영수증에서 (1) 가맹점명, (2) 거래 일시, (3) 총 금액, (4) 부가세, (5) 공급가액을 추출해. - 모든 이미지의 추출·확인 필요 항목을 정리한 뒤 Code interpreter로 엑셀을 만들어. - 기본 시트는 "가맹점명 / 거래 일시 / 총 금액 / 부가세 / 공급가액"의 5열로 작성해. - 원본 파일명·누락·불일치·중복 의심 내역은 별도 "확인 필요" 시트와 답변에 기록해. 중복으로 보이는 이미지를 임의 삭제하지 마. - 대화창에 시트 미리보기를 보여주고 엑셀 다운로드를 제공해. 답변은 한국어로 해. # 필드별 규칙 1. 가맹점명은 영수증에 인쇄된 판매자 상호 전체를 사용해. 예: 실습문구센터(가상). 주소·담당자 이름을 상호로 바꾸지 마. 2. 거래 일시는 날짜를 YYYY-MM-DD 형식으로 기록해. 예: 2026-09-07. 날짜가 불명확하면 확인 필요. 3. 총 금액·부가세·공급가액은 확인된 경우 숫자로 입력해. 쉼표·원 표시는 제거하고 숫자형 셀로 저장해. 4. 부가세·공급가액이 영수증에 있으면 그대로 읽어. 누락·판독 불가·인쇄 누락이면 확인 필요로 남겨. 0원으로 바꾸거나 일반 세율을 적용해 추정하지 마. 5. 총 금액·부가세·공급가액이 모두 읽혔을 때만 합계 관계를 검산해. 맞지 않으면 원문을 유지하고 불일치를 표시해. 누락된 필드를 총액에서 역산해 채우지 마. # 예외 처리·실패 폴백 - 이미지가 흐리거나 잘렸으면 "이 영수증은 제대로 인식되지 않았습니다. 원본 이미지를 다시 올리거나 해당 정보를 수동 확인해 주세요."라고 알려줘. - 부분만 읽혔으면 확인된 필드는 유지하고 나머지는 확인 필요로 표시해. - ZIP 해제나 엑셀 생성이 불가능한 환경이면 가능한 단계와 막힌 단계를 구분하고, 이미지 개별 업로드 또는 복사 가능한 표를 안내해. 파일을 만들지 못했다면 다운로드 링크를 지어내지 마. - 처리한 이미지 수와 추출 행 수가 일치하는지 대조하고, 누락된 부가세·공급가액이 확인 필요로 남아 있는지 마지막에 점검해.
