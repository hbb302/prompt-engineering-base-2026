1-2 · 첫 요청 — 원하는 결과만 말한다

채울 열과 참고할 표를 알려주면 AI가 알맞은 함수를 제안합니다.

PROMPT 1 · 첫 요청 (구조 파일 첨부 후)
미래엔 전사 AI 교육 신청 명단을 정리하고 있어. 첨부 파일은 구조 사본이고, 원본에는 2~151행에 신청자 150명이 있어. 부서명은 부서코드표에서, 프로그램명·교육시간은 프로그램표에서 코드에 맞게 가져오고 싶어. I2:K2에 넣을 수식을 만들어줘. 아래로 채워도 기준 범위가 바뀌지 않게 해줘. 열별 수식, 작동 원리 한 줄, 원본에 적용하는 순서로 알려줘.
원본의 2행에 수식을 넣고 151행까지 채웁니다. 셀 오른쪽 아래 채우기 핸들을 더블클릭하고, 마지막 행까지 적용됐는지 확인합니다.

1-3 · 계산 규칙을 수식으로

교육시간 × 시간당 단가 × 지급률처럼 계산 규칙을 구체적으로 알려줍니다.

PROMPT 2 · 복합 산정 (규칙 명시)
이번에는 신청자별 예상 지원금(L열)을 계산하려고 해. 교육시간에 프로그램표의 시간당 지원단가를 곱하고, 사전과제 Y는 전액, N은 절반을 지급하는 실습 규칙이야. 프로그램코드로 단가를 찾아 계산하는 L2 수식을 만들어줘. 아래 행에도 채울 수 있어야 해. 계산 과정과 원 단위·천 단위 구분 표시 방법을 설명하고, Y와 N 각각 한 건을 검증하는 방법도 알려줘.
수식은 업무 규칙을 반복합니다. 기준표에서 값을 찾고, 조건을 판단하고, 계산하는 작업을 한 번에 처리합니다.

1-4 · 검증과 디버깅 — AI도 틀린다

신청자 한 명을 골라 직접 계산한 값과 대조합니다. 차이가 나면 사용한 수식과 조건을 알려주고 수정합니다.

PROMPT 3 · 디버깅 (결과가 이상할 때)
사전과제가 N인 신청자의 지원금이 전액으로 계산됐어. 현재 수식은 [내 수식], 교육시간은 [시간], 시간당 단가는 [금액]이야. 계산 과정을 확인해 원인을 짚고, N은 절반·Y는 전액이 되도록 고쳐줘. 수정한 수식의 예상값도 알려줘.
수정 후에도 다시 대조합니다. 참조 범위와 지급 조건을 확인하세요. #NAME?가 뜨면 엑셀 버전과 오류를 알려주고, 지원되는 함수로 바꿔 달라고 요청합니다.

1-5 · 조건 판정 — 우선선발 가리기

PROMPT 4 · 판정 규칙 명시
신청자가 정원을 넘었을 때 참고할 우선선발(M열) 수식을 만들고 싶어. 사전과제 제출이 Y이면서 작년 이수시간이 20시간 미만이면 “우선”, 나머지는 “일반”으로 표시해줘. 두 조건을 모두 만족해야 해. M2 수식과 아래로 채우는 방법을 알려줘. Y·19시간, Y·20시간, N·19시간의 판정도 예로 확인해줘.

1-6 · 프로그램별 신청 현황 집계

CASE 3 VBA 매크로 × AI — 거래명세서 자동 발급

명세서 발급, 버튼 한 번으로 끝낸다연수가 끝나면 정산이 남습니다. 건별로 양식을 채워 PDF로 만들던 일 — 러프한 한마디에서 시작해, 동작하는 코드를 받아냅니다.

상황. 협력업체·외부 강사 정산 시즌입니다. 거래 건마다 거래명세서 양식을 채워 PDF로 발급해 왔습니다 — 거래처명 바꾸고, 품목 넣고, 금액 넣고, 저장하고, 또 다음 건. 실습 파일에는 시트 1(명세서 양식)과 시트 2(거래 데이터 수십 건)가 들어 있습니다. 오늘은 이 반복을 코드 한 번으로 끝냅니다 — 코드는 여러분이 아니라 AI가 짭니다. (회사마다 서류 명칭은 다르지만, 건별로 양식을 채워 PDF로 내보내는 서류라면 구조는 같습니다)

VBA 한 줄 개념. 엑셀 안에 내장된 자동화 언어입니다. 우리는 직접 코딩하지 않고 AI에게 받아서 붙여넣습니다. 매크로가 든 파일은 .xlsm 형식으로 저장해야 코드가 보관되고, 열 때 보안 경고는 "콘텐츠 사용"으로 허용합니다.

3-1 · 머릿속에 떠오르는 대로 적는다

구조화된 프롬프트를 처음부터 잘 쓸 필요 없습니다. 실습 파일을 첨부하고, 하고 싶은 작업을 한 덩어리 글로 풀어 적습니다 — 이것이 현실적인 출발점입니다.

PROMPT 10 · 러프한 첫 요청 (파일 첨부 후)
이 엑셀파일 양식 파악해서 거래명세서 자동발급 VBA 코드 만들어줘. 1번 시트는 거래명세서 양식이고, 2번 시트는 거래명세서에 들어갈 변수값 데이터야. 2번 시트 데이터를 입력하고 VBA 코드를 실행하면, 각 데이터를 거래명세서 양식에 적용하고 각 데이터별 PDF 파일을 생성하는 작업이어야 해. 파일 저장 경로도 설정할 수 있게 만들어줘.

3-2 · AI에게 마스터 프롬프트로 정돈시킨다

러프한 요청을 그대로 코드로 만들면 동작하지 않는 코드가 나오기 쉽습니다. "마스터 프롬프트로 정돈해 달라"고 한 단계 띄워 요청합니다.

PROMPT 11 · 마스터 프롬프트 정돈 요청
아래는 내가 만들고 싶은 VBA 자동화 작업의 러프한 요청이야. 이걸 그대로 던지면 동작 안 하는 코드가 나올 가능성이 높아. 부족하거나 빠진 맥락(값을 채울 위치, 파일명 규칙, 예외 처리 등)을 업계 통상에 맞춰 보강해서 마스터 프롬프트 형태로 정돈해줘. 첨부한 파일의 실제 구조를 근거로 삼고, 내가 추가로 확인해야 하는 부분은 [채워주세요] 빈칸으로 표시해줘. --- 러프한 요청 --- 이 엑셀파일 양식 파악해서 거래명세서 자동발급 VBA 코드 만들어줘. 1번 시트는 거래명세서 양식, 2번 시트는 데이터. 2번 시트 데이터로 1번 양식 채우고 각 행별 PDF로 저장. 파일 경로 설정 가능해야 함.
돌아오는 것. 작업 개요 · 값 채울 위치 · 파일 저장 규칙(예: "거래명세서_[거래처명]_[날짜].pdf") · 예외 처리(빈 행 중단, 파일명 중복)까지 정돈된 마스터 프롬프트가 돌아옵니다. [채워주세요] 빈칸만 내 상황에 맞게 채우면 됩니다.

PROMPT 12 · 채워진 마스터 프롬프트로 코드 요청
위 마스터 프롬프트에 내 파일 기준으로 빈칸을 채웠어. 이 조건대로 동작하는 VBA 코드를 작성해줘. [채워진 정보] - 양식 시트(거래명세서): 값이 들어갈 자리가 {거래처명} {월} {일} {품목명} {수량} {단가} {공급가액} {총액} 같은 표시로 적혀 있어 — 이 표시를 데이터 값으로 바꿔 넣으면 돼 - 데이터 시트(거래처 명단): A발송일자, B거래처명, C품목명, D수량, E단가, F공급가액 — 2행부터 데이터 - 저장 경로: 코드 상단 변수로 두고, 기본값은 savePath = "C:\거래명세서\" - PDF 파일명: "거래명세서_(거래처명)_(발송일자).pdf" [출력 형식] 1. VBA 코드 전체 (Module1에 붙여넣는 형태, 블록마다 주석 한 줄) 2. 사용 방법 (Alt+F11 → 모듈 삽입 → 붙여넣기 → 실행) 순서 3. 실행 전 확인할 점 (저장 폴더 미리 만들기 등)

3-4 · 실행 — PDF가 다발로 쏟아진다

  • 탐색기에서 C:\거래명세서\ 폴더를 먼저 만들어 둡니다 (저장 경로)
  • 엑셀에서 Alt + F11 → 메뉴 삽입 → 모듈 → 받은 코드를 붙여넣기
  • 코드 상단 savePath가 내 폴더 경로와 같은지 확인
  • F5(실행) → 폴더를 열면 — 거래 건수만큼 명세서 PDF가 생성되어 있습니다
  • PDF 한 장을 열어 양식에 값이 제대로 들어갔는지 확인 → 파일을 .xlsm으로 저장(코드 보관)
막혔을 때. 오류 창이 뜨면 — 메시지를 그대로 복사해 "이 오류 고쳐줘". 디버깅도 위임 대상입니다. 회사 PC 보안 설정으로 매크로가 차단되면 정보보안 부서 확인이 필요합니다 — 오늘은 옆자리 화면과 함께 결과를 확인하고, 코드는 받아 두세요.
방금 일어난 일.

코드를 한 줄도 쓰지 않고, 수십 건의 서류 발급이 버튼 하나가 됐습니다. 이 흐름 — 러프 → AI 정돈 → 동작 코드 — 은 견적서·발주서·확인서에도 90% 그대로 재활용됩니다.

CASE 4 구글 폼 + 앱스 스크립트

신청하면 안내 메일이 자동으로구글 폼과 Apps Script를 연결해 접수 안내를 자동화합니다.

교육 신청이 들어오면 접수 확인 메일이 자동 발송되게 만듭니다. 본인 이메일과 가상 이름으로 테스트합니다.

Apps Script는 구글 업무 도구를 연결하는 코드입니다. 트리거를 설정하면 폼 제출 같은 조건이 생겼을 때 자동으로 실행됩니다.

4-1 · 신청 폼 만들기

  • forms.google.com 접속 → 새 양식 → 제목 「실습용_미래엔 전사 AI 교육 신청」
  • 아래 문항 3개를 만듭니다. 이메일 문항은 응답 확인 → 텍스트 → 이메일 주소로 형식을 검사합니다
  • 이메일 주소 자동 수집은 사용하지 않고 아래 이메일 문항으로 입력받습니다. 폼의 응답 권한에 본인 테스트 계정이 포함돼 있는지 확인합니다
  • 응답 탭 → Sheets에 연결 — 응답이 쌓일 스프레드시트가 만들어집니다
폼에 직접 만들 문항
1. 성명 — 단답형 2. 이메일 — 단답형 3. 희망 과정 — 객관식 (교육콘텐츠 검수 심화 / 교육사업 데이터 분석 / 고객응대 자동화)

4-2 · 자동 회신 스크립트 받기

  • 연결된 스프레드시트 열기 → 메뉴 확장 프로그램 → Apps Script
  • 새 프로젝트에 아래 요청으로 받은 코드를 붙여넣기 → 저장
PROMPT 13 · 앱스 스크립트 요청
미래엔 AI 교육의 실습용 구글 폼 접수 안내를 자동화할 Apps Script를 만들어줘. 응답 시트의 성명·이메일·희망 과정을 열 번호 대신 문항 이름으로 읽고, 폼 제출 시 입력된 이메일로 확인 메일을 보내줘. 제목은 “[실습용·미래엔 AI 교육] 접수 확인”, 본문은 성명·희망 과정과 “교육 실습용이며 실제 신청이 아닙니다”를 넣어줘. 내가 지정한 주소로 한 통 보내는 별도 테스트 함수도 만들어줘. 주소를 바꿀 위치를 표시해줘. 전체 코드와 저장 → 테스트·권한 승인 → 스프레드시트의 ‘양식 제출 시’ 트리거 설정 순서를 알려줘.

4-3 · 테스트 함수 실행과 권한 승인

트리거 연결 전에 테스트 함수를 실행해 필요한 권한을 승인합니다.

  • 코드의 테스트 주소를 내 이메일로 바꾸고 저장합니다.
  • 편집기 상단에서 테스트 함수(AI가 만들어 준 것)를 선택 → ▶ 실행 클릭
  • 「권한 검토」 창이 뜹니다 → 내 구글 계정 선택
  • 미확인 앱 안내가 나오면 본인이 만든 프로젝트인지 확인합니다. 진행이 허용된 계정에서는 고급 메뉴에서 프로젝트로 이동합니다
  • 메일 발송 등 요청 권한을 확인하고 승인합니다. 필요한 권한은 AI가 만든 코드에 따라 달라집니다
  • 받은편지함에 테스트 메일이 도착했으면 권한 완료 — 이제 자동화를 걸 수 있습니다
계정 정책으로 실행이 막히면 강사가 안내한 실습용 계정과 가상 자료로 진행합니다. 회사 계정의 제한을 임의로 바꾸지 않습니다.

4-4 · 양식 제출 시 트리거 연결

  • 편집기 왼쪽 ⏰ 트리거 메뉴 → 오른쪽 아래 트리거 추가
  • 실행할 함수 = 폼 제출 처리 함수(테스트 함수 아님) → 이벤트 소스 스프레드시트에서 → 이벤트 유형 양식 제출 시 → 저장
  • 목록에서 선택한 함수와 이벤트 유형을 확인합니다

4-5 · 폼 제출로 작동 확인하기

  • 폼의 응답자 링크를 열어 테스트 계정으로 응답할 수 있는지 확인합니다
  • 그 상태로 내 이메일을 입력해 신청을 제출합니다 — 입력한 주소로 메일이 와야 합니다
  • 받은편지함 확인 — 접수 확인 메일에 내 성명과 희망 과정이 채워져 있는지 봅니다 (안 보이면 스팸함도 확인)
  • 메일이 안 오면: 편집기 왼쪽 실행 기록 메뉴 → 실패한 실행을 클릭 → 오류 메시지를 복사해 AI에게 "이 오류 고쳐줘"
  • 수정 코드를 저장하고 다시 제출해 확인합니다. 실습 후에는 테스트 트리거를 삭제합니다
완료 기준은 실제 메일 수신입니다. 이 실습은 별도 배포 없이 스프레드시트의 '양식 제출 시' 트리거로 동작합니다. 폼을 제출하고 결과를 확인하세요. 트리거 도움말

자동화하고 싶은 내 업무 하나를 골라 아래 항목을 적습니다.

내 업무를 떠올리며 작성
업무 이름: 예) 주간 업무 보고 반복 주기: 매일 / 매주 / 매월 입력 → 처리 → 출력: 예) 팀별 자료 → 취합·요약 → 보고서 가장 줄이고 싶은 작업: 활용할 도구 또는 CASE 번호:

자주 반복되고, 규칙이 분명하며, 입력과 출력이 있는 업무부터 고릅니다.

마치기 전 점검

Checklist
  • 데이터를 지운 구조 파일을 만들어 첨부했다 — 함수 이름 없이 원하는 결과만 말했다
  • 수식을 받을 때 "설명해줘"를 함께 요청했다 · AI가 낸 집계 중 최소 1개를 직접 대조했다
  • 거래명세서 매크로를 실행해 PDF가 자동 생성되는 것을 확인했다 (오류는 메시지를 복사해 AI에게)
  • 내 폼으로 신청을 넣어 자동 확인 메일 수신을 확인했다
  • 보고 장표를 최소 1종 완성해 저장했다
  • 자동화 과제 카드를 작성했다
  • 실습에는 더미 데이터만 사용했고, 실제 업무 데이터 사용 전 회사 보안 정책 확인이 필요함을 안다
