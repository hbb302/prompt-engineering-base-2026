# 미래엔 전사 AI 실무 활용교육

프롬프트 엔지니어링 9개 PART와 업무자동화[엑셀편] 5개 CASE로 구성한 미래엔 임직원 전사교육용 교안입니다.

## 실습 흐름

- 본편: 가상 부서협업 TF가 교사 지원 서비스 개선 보고서를 작성합니다. 회의 맥락과 이전 보고서 예시를 활용하고, 공개 자료 조사, 마크다운 정리, 마스터프롬프트, 섹션별 작성, 작업 스타일 추출, GPTs 재사용으로 이어집니다.
- 엑셀편: 가상 전사 AI 교육의 신청 명단, 만족도 응답, 접수 안내와 결과 보고를 다룹니다.
- VBA 설명·프롬프트·실행 절차와 `거래명세서 샘플.xlsx`는 기본 교안 그대로입니다.

## 자료 사용 순서

| 단계 | 첨부하거나 비교할 파일 |
| --- | --- |
| PART 02 | `교안_자료/회의록_교사지원개선_TF_STT.txt`, `퓨샷_이전분기_학습자료배포개선.docx` |
| PART 03~04 | 직접 조사한 결과 또는 `교안_자료/리서치결과_백업_개선후보3안.md` |
| PART 05~06 | 회의록·퓨샷·본인이 정리한 리서치. 완성 후 앵커 보고서와 비교 |
| PART 08 | `교안_자료/실습용 영수증.zip`의 가상 영수증 7장. 추출 후 OCR 검증기준 CSV와 대조 |
| CASE 1 | `업무자동화_자료/실습1_연수_신청자명단.xlsx`. 먼저 구조만 남긴 사본을 만들고 완성예시는 마지막에 비교 |
| CASE 2 | `업무자동화_자료/실습2_만족도_설문응답.xlsx` |
| CASE 3 | `업무자동화_자료/거래명세서 샘플.xlsx` |
| CASE 4 | 교안에 따라 새 실습용 구글 폼 작성 |
| CASE 5 | `업무자동화_자료/실습5_만족도_분석요약.md` 또는 동일 내용의 DOCX |

자료 묶음 전체를 한 번에 AI에 올리지 말고, 교안의 해당 단계에 안내된 파일만 첨부합니다. 정답과 완성예시는 작업 후 검증에 활용합니다.

## 실습 자료의 범위

TF·인물·회의·일정·조직 명칭·교육제도·지원금 규칙·응답·영수증은 교육용 가상 자료입니다. 실제 미래엔의 내부 문서·정책·계획·고객 정보·실적을 나타내지 않습니다. 공개 서비스 정보와 개선 제안·효과 가설을 구분합니다.

신청자 150명과 만족도 응답 72명은 별도 표본입니다. 신청본과 완성본의 원본 행은 같으며, 과정별 신청률의 분모는 해당 과정 정원입니다.
