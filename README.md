# 미래엔 전사 AI 실무 활용교육

프롬프트 엔지니어링 9개 PART와 업무자동화[엑셀편] 5개 CASE로 구성한 교안입니다.

## 실습 흐름

본편에서는 **사내 AI 활용 교육 운영 기획안** 하나를 완성합니다. 회의 맥락과 이전 기획안을 활용해 요청을 구체화하고, 조사, 마크다운 정리, 마스터프롬프트, 섹션별 작성, 작업 스타일 추출, GPTs 재사용으로 이어집니다.

프롬프트 예시를 읽고 필요한 내용을 직접 입력합니다. 자기 업무에 맞게 대상과 상황을 바꿔도 좋습니다.

엑셀편은 가상의 전사 AI 교육 신청 명단, 만족도 응답, 접수 안내와 결과 보고를 다룹니다. VBA 설명·프롬프트·실행 절차와 거래명세서 샘플은 기본 교안 그대로입니다.

## 자료 사용 순서

| 단계 | 사용할 파일 |
| --- | --- |
| PART 02 | `교안_자료/회의록_사내AI교육_기획회의_STT.txt`, `교안_자료/퓨샷_사내업무공유세미나_기획안.docx` |
| PART 03~04 | 직접 조사한 결과 또는 `교안_자료/리서치결과_백업_사내AI교육.md` |
| PART 05~06 | 회의록·이전 기획안·정리한 조사 결과. 완성 후 `교안_자료/앵커_사내AI교육_기획안.docx`와 비교 |
| PART 08 | `교안_자료/실습용 영수증.zip`의 가상 영수증 7장. 결과를 `교안_자료/영수증_OCR_검증기준.csv`와 대조 |
| CASE 1 | `업무자동화_자료/실습1_연수_신청자명단.xlsx`. 완성예시는 작업 후 비교 |
| CASE 2 | `업무자동화_자료/실습2_만족도_설문응답.xlsx` |
| CASE 3 | `업무자동화_자료/거래명세서 샘플.xlsx` |
| CASE 4 | 교안에 따라 새 실습용 구글 폼 작성 |
| CASE 5 | `업무자동화_자료/실습5_만족도_분석요약.md` 또는 동일 내용의 DOCX |

각 단계에서 안내한 파일만 AI에 첨부합니다. 기획안 작성 틀은 `교안_자료/양식_사내AI교육_기획안.md`에서도 확인할 수 있습니다.

## 자료 안내

인물·회의·운영 계획·신청자·응답·지원금 규칙·영수증은 교육용 가상 자료입니다. 실제 미래엔의 내부 문서나 정책을 나타내지 않습니다. 신청자 150명과 만족도 응답 72명은 별도 표본입니다.
