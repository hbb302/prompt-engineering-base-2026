# 교사 연수 운영경비 OCR 실습

미래엔 전사교육을 위한 교육용 가상 영수증 7장입니다. 실제 미래엔의 거래·정산 정책·지출 자료가 아니며 증빙으로 사용할 수 없습니다.

1. 완성한 경비 정리 챗봇에 `실습용 영수증.zip`을 업로드합니다. ZIP을 읽지 못하면 압축을 풀고 PNG 7장을 올립니다.
2. 이미지마다 가맹점명, 거래 일시(YYYY-MM-DD), 총 금액, 부가세, 공급가액을 추출합니다.
3. 처음에는 정답 CSV를 올리지 않습니다. OCR 결과를 받은 후 `영수증_OCR_검증기준.csv`와 비교합니다.
4. 1~6번은 금액 세 항목의 합계를 점검합니다. 7번은 세액과 공급가액이 누락되어 있습니다. 세율을 가정해 채우지 말고 두 값을 ‘확인 필요’로 남기는지 확인합니다.
5. Excel 다운로드 파일을 열어 7개 행, 5개 추출 필드, 날짜·숫자·누락 처리가 일치하는지 검증합니다. 검증 기준 파일의 이미지명과 확인사항은 대조용 열입니다.

이 실습의 결과는 사람이 검토할 추출 초안입니다. 비용 인정 여부, 세금 판단 또는 정산 승인까지 자동 확정하지 않습니다.
