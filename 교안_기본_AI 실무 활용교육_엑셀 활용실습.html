영수증 30장 → 엑셀. 손으로 옮겨 적으면 1시간, AI에 맡기면 3분. 핵심은 구조화된 프롬프트 하나다.

'가맹점명(상호명)'은 이 상품을 판매한 매장, 식당, 회사의 이름이다. '가맹점명(상호명)'은 다음과 같은 조건에 하나 이상 해당한다. - '(주)'가 포함된 전체 텍스트 (예: 아성다이소_홍대2호점) - 매장명 or 상호명 or 가맹점 or 상호 바로 뒤에 위치한 전체 텍스트 - 매장 주소 or 대표자 직전에 나오는 고유명사 전체 텍스트 - 영수증 최상단에 큰 글씨로 적힌 이름 2. '거래 일시'는 YYYY-MM-DD 포맷으로 작성해 (예: 2024-08-15) 3. '총 금액'은 거래한 총 금액이다. 문자나 특수기호는 제거하고 숫자만 출력해 (예: 11955) 4. '부가세'는 이 거래에서 부가세가 있는 경우 적어줘. 문자나 특수기호는 제거하고 숫자만 출력해 (예: 1195) 5. '공급가액'은 '총 금액'에서 '부가세'를 뺀 숫자야 6. 정보 추출이 어려울 때는 '이 영수증은 제대로 인식되지 않았습니다. 다른 이미지를 업로드 하시거나 수동으로 정보를 피드백해 주세요.'라고 알려줘

프롬프트 구조 — 4가지 기둥

같은 패턴은 다른 자동화 프롬프트(명함 정리·세금계산서·계약서 추출 등)에 그대로 옮길 수 있다.

구조 1지시문 (작업 순서)

"이미지 인식 → 데이터 추출 → 엑셀 기록 → 다운로드 제공"까지 실행 순서를 단계별로 명시. AI가 임의로 단계를 합치거나 빼지 않도록 통제.

구조 2예외 처리 명시

"여러 장이면 한 개씩" / "Code interpreter는 OCR 단계에서 쓰지 마" / "인식 안 되면 이렇게 알려" — 흔한 실수를 사전에 차단.

구조 3필드별 추출 규칙

가맹점명은 4가지 조건 중 하나 / 거래일시는 YYYY-MM-DD / 금액은 숫자만 — 각 컬럼의 데이터 형식을 명확히 정의해 결과 편차 제거.

구조 4실패 시 폴백

"정보 추출이 어려울 때는 이렇게 안내해" — AI가 거짓 데이터를 만들지 않고 정직하게 실패 신호를 보내도록 유도.

PRACTICE 2 엑셀 함수 X AI — 단순 함수부터 복합 함수까지

엑셀 함수를 외우지 않고 AI에게 시킨다"이렇게 만들어줘"만으로 SUMIFS · INDEX/MATCH · VLOOKUP 까지

함수 이름 검색 = 가장 큰 시간 낭비. "이걸 이렇게 계산해줘" 한 줄이면 AI가 적절한 함수식을 만들어준다.

실습 시나리오 — 판매 데이터 분석

함수 검색 X → 자연어 요청 O.

INPUT판매 데이터 시트

날짜 · 지점 · 카테고리 · 제품명 · 수량 · 단가 등 영업 데이터.

PROCESS자연어로 함수 요청

AI가 적절한 함수식(SUMIFS / COUNTIFS / INDEX-MATCH 등)을 생성.

OUTPUT그대로 셀에 붙여넣는 함수

복사 → 셀에 붙여넣기 → 결과 확인. 함수를 외울 필요 없음.

다운로드

5단계 실습 — G·H·I·J·K 컬럼을 차례로

곱셈 → 조건 수식 → AI 디버깅 → 시트 간 조회 → 조건부 선정.

1단계 · G열 매출액 — 단순 곱셈

먼저 데이터 구조 파악 → 가장 단순한 곱셈부터.

PROMPT 1 — 데이터 구조 분석 + 매출액 수식
sales_data 파일이야. 이 데이터 구조 분석해서 G열 매출액 칼럼에 넣을 수식 알려줘.

2단계 · H열 기여도 % — 조건 명시 요청

"수식 줘"만 X. 비율 기준 / % 표시 / 소수점 자리 / 합계 검증까지 명시.

PROMPT 2 — H열 기여도 칼럼 수식 (조건 명시)
좋아, H열 기여도 칼럼도 채울 거야. 수식 알려줘. - 기여도는 G열 매출액 데이터를 기반으로 총 매출액 대비 각 데이터의 비율을 나타낸다. - 기여도는 %로 표시한다. - 소수점 둘째 자리까지만 나타낸다. 셋째 자리에서 반올림. - 기여도의 총 합산이 반드시 100이 되어야 한다.

3단계 · AI도 틀린다 — 디버깅

AI 결과 그대로 믿지 X. 결과 이상 → 즉시 "원인 분석해서 다시 줘". 가장 중요한 단계.

PROMPT 3 — 디버깅 (잘못된 수식 검증)
지금 H2 값에 수식 넣어봤는데 55.00%로 나온다. 이게 말이 되냐? 문제 원인 분석해서 제대로 된 함수 가지고 와.
중요 — AI 결과는 항상 검증한다. 합계가 100이 안 나오거나 비정상 값이 나오면 즉시 다시 요청. AI는 첫 답에서 절대 참조($)를 빠뜨리거나 잘못된 범위를 쓰는 경우가 흔합니다. "결과가 이상하다 → 원인 분석해서 다시 줘" 한 마디면 AI가 SUM 범위 절대 참조 문제 등을 스스로 찾아 수정해 줍니다.

4단계 · I·J열 — 시트 간 조회 (VLOOKUP/XLOOKUP)

상품 코드 → 다른 시트에서 상품명/카테고리 매칭.

PROMPT 4 — I열 상품명 · J열 카테고리 (시트 간 조회)
I열 상품명 칼럼 채우자. 수식 줘. - C열 상품 코드에 맞는 상품명을 product 시트에서 찾아서 매칭된 값을 채워 넣는다. J열 카테고리 칼럼도 같이 해줘. 동일한 방식으로.

5단계 · K열 상위매출 — 조건부 순위 (LARGE + IF)

"매출 상위 5건만 'O' 표기" — 복잡한 식도 자연어로 OK.

PROMPT 5 — K열 상위매출 선정 (조건부 표기)
K열 칼럼 수식 알려줘. 상위매출 선정 내용이다. - G열 매출액을 기준으로 상위 5개 데이터만 선정해서 상위매출로 표기한다. - 선정된 데이터는 'O'로 표기한다. - 비선정된 데이터는 공란으로 둔다.
학습 포인트 — 함수 이름은 외울 필요 없다. "무엇을 계산할지" + "결과 조건" 두 가지만 자연어로 말하면 AI가 함수 조합 + 동작 원리까지 같이 설명. 가장 중요한 건 3단계 디버깅 감각 — AI 결과 검증 없이 쓰면 실무 사고.
다음 단계 — 함수에서 자동화로. 5개 컬럼 작업을 새 데이터에도 자동 적용하려면 함수 X → 매크로/스크립트 O. 다음 실습 (Practice 3 VBA · Practice 4 Apps Script)에서 다룸.
주의 — AI는 데이터 구조를 봐야 정확합니다. 컬럼명을 추측해서 답하면 셀 참조가 어긋날 수 있습니다. 가능하면 엑셀 파일을 먼저 첨부해 AI가 시트 구조를 확인한 뒤 함수식을 요청하세요. 회사 보안상 파일 업로드가 어렵다면 첫 메시지에 컬럼명 · 데이터 범위 · 시작 행을 텍스트로 알려준 후 요청합니다.
PRACTICE 3 엑셀 VBA 자동화 — 거래명세서 자동 발급

러프한 한 마디를 AI가 마스터 프롬프트로 보강 → 동작하는 VBA 코드 받기"이거 이렇게 만들어줘" 한 줄로 시작해 거래명세서 100건을 자동 생성한다

거래명세서 · 견적서 · 발주서 100건 → 버튼 한 번. 코드 못 짜도 OK. 러프 요청 → 마스터 프롬프트 → 동작 코드 3단계.

VBA란? — 한 줄 정리

엑셀에 내장된 자동화 언어. 1993년부터 MS Office 기본 탑재. 별도 설치 X.

WHAT엑셀 안의 자동화 언어

엑셀 메뉴 → 개발 도구 → Visual Basic에서 코드를 작성. 셀 값 읽고 쓰기 · 시트 복제 · PDF 저장 · 메일 발송까지 모두 가능.

WHY반복 업무 0초화

거래명세서 100건 · 견적서 50건 · 월별 보고서 양식 — 사람이 1시간 걸리는 작업을 버튼 한 번 클릭으로 끝낸다.

HOWAI에게 코드 생성 요청

"이런 작업 자동화하는 VBA 코드 만들어줘" → AI가 코드 작성 → 엑셀 모듈에 붙여넣기 → 실행. 직접 코딩 안 해도 됨.

WHERE매크로 사용 파일 (.xlsm)
